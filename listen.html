LISTENING BENCH

Every voice the machine has, in the states worth hearing it in. Each one is rendered through the same graph the cab plays, on an offline context, and handed to you as a file — so what you hear here is what you would hear in the seat. Nothing below is simulated: a scene holds one condition still long enough to listen to it, which a real run refuses to do.

npm run listen renders the same set to renders/ and prints what it measured.
